## Prerequisites

- **[Homebrew](https://brew.sh/)**
- [NodeJS +22](https://formulae.brew.sh/formula/node@22)
- [Yarn](https://formulae.brew.sh/formula/yarn#default)

- [Allure](https://formulae.brew.sh/formula/allure#default)

**NOTE:** The project use Node v22 (.nvmrc). It is recommended to use nvm to manage different Node versions in your
environment.

## Configuration

> Tips:

Use the **Homebrew** to download the packages.

### Examples

> Java (Temurin):

```bash
brew install --cask temurin
```

> Vscode:

```bash
brew install --cask visual-studio-code
```

> Node v22:

```bash
brew install node@22
```

> To clone the project:

```bash
git clone https://github.com/doutorfinancas/employee-management-tests.git
```

- Use the terminal to install the dependencies on __package.json__, for example:

```bash
yarn
```

> IMPORTANT:

- Do not expose sensitive data:

It's necessary to create a root `.env` file of the project as in the example: `.env.example`.

Example for data below:

```env
EMPLOYEE_MANAGEMENT_API=https://clinica-frontops.staging.aws.doutorfinancas.pt
ID_API=https://clinica-frontops-id.staging.aws.doutorfinancas.pt
EMPLOYEE_MANAGEMENT_E2E=https://employee-management.staging.aws.doutorfinancas.pt
TEST_USER_EMPLOYEE=automation_test_frontops@doutorfinancas.pt
TEST_PASSWORD=Test@12345
```

After creating the .env, your tests are ready to run.

## Installation

> To clean the project & install all dependencies via **package.json**:

```bash
cd /employee-management-tests
yarn clean
yarn install
yarn playwright install
```

## How to run Local test

After confirming the previous settings, follow the steps below:

> To run all API tests:

```bash
yarn test:api
```

> To run all UI tests:

```bash
yarn test:e2e
```

> To run with all tests (API and UI):

```bash
yarn test:all
```

> To run debug mode:

Set PWDEBUG: `set PWDEBUG=1`

```bash
PWDEBUG=1 yarn test:e2e
```

> To run with open browser mode:

```bash
npx playwright test --headed
```

## How to run Docker test

You can run the tests using Docker. First:

> To build the image:

```bash
yarn docker:build
```

> To run API tests:

```bash
yarn docker:api
```

> To run E2E tests:

```bash
yarn docker:e2e
```

> To run ALL tests:

```bash
yarn docker:all
```

All test results will be available in the `allure-results` directory and a report is generated automatically.

## How to view the Report

Reports are generated by [Allure](https://github.com/allure-framework).

It's necessary to have **Allure** installed in the project (via package) or in your machine according to the *
*Installation** topic of this README.

> To generate the report inside an allure server:

```bash
yarn allure:report
```

**IMPORTANT!**

The Allure report is automatically published to **GitHub Pages** after each execution.

> To access the report:

- [REPORT: GH-PAGES](https://doutorfinancas.github.io/employee-management-tests)
